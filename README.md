# Учёт пациентов

Настольное приложение (Python, tkinter, matplotlib) для ведения списка пациентов и построения сводной статистики.

## Возможности
- Таблица пациентов: ФИО, возраст, пол, рост (см), вес (кг), ИМТ.
- Добавление пациента.
- Редактирование (кнопка «Редактировать» или двойной щелчок по строке).
- Сводная статистика (4 графика):
  1. распределение пациентов по полу;
  2. распределение пациентов по возрасту;
  3. распределение ИМТ с учётом пола;
  4. зависимость ИМТ от возраста.
- Данные сохраняются в файл `patients.json` после каждого изменения и загружаются при запуске.

## Требования
- Python 3.9+
- tkinter (входит в стандартную установку Python и в сборку conda)
- matplotlib

## Установка (conda)
```bash
conda create -n patients python=3.11 matplotlib
conda activate patients
```

## Установка (pip)
```bash
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install matplotlib
```

## Запуск
```bash
python patients.py
```

## Формат данных (`patients.json`)
```json
[
  {"name": "Иванов Иван Иванович", "age": 35, "sex": "Мужской",
   "height": 180.0, "weight": 80.0, "bmi": 24.7}
]
```

## Расчёт ИМТ
ИМТ = вес (кг) / (рост (м))^2, округляется до 0,1.

## Ограничения ввода
- Возраст: 0-120 лет; рост: 30-250 см; вес: 2-400 кг.
- Пол: «Мужской» или «Женский».
